# Pelclo — Контент-штаб

Личный адаптивный интерфейс для планирования Reels, Stories, каруселей и Telegram-постов.

## Текущая версия
- Главная со сводкой по материалам
- Календарь публикаций
- Редактор текстов и статусов
- Медиатека по ссылкам
- Экспорт/импорт резервной копии JSON
- Мобильная навигация

Данные хранятся **только в localStorage текущего браузера**. Это прототип без авторизации. Он не синхронизируется между устройствами и не публикует посты автоматически.

## Публикация
В репозитории есть workflow GitHub Pages. Открой Settings → Pages → Build and deployment → Source: **GitHub Actions**. После этого запусти workflow Deploy Content HQ to GitHub Pages (или сделай новый коммит).

Ожидаемый адрес после успешного развёртывания: https://dinooon0511.github.io/pelclo_shtab/

## Безопасность
GitHub Pages — публичный сайт. Не добавляй в frontend токены Telegram, GitHub PAT, Supabase service_role и личные данные. Telegram-публикатор остаётся в отдельном приватном репозитории pelclo_tg.
